# Lumen Dental Studio — Premium Package (Concept)

Premium multi-page website for a cosmetic & family dental clinic in Scottsdale, AZ.

**Features**
- 4-step online booking: service & dentist → availability calendar with time slots → patient details with validation → review & confirm; confirmation ticket, .ics / Google Calendar export, cancel, saved in localStorage
- Smile cost estimator: pick treatments & quantities, self-pay / PPO insurance (with annual maximum) / membership, monthly payment plans
- Before / after comparison slider with case tabs
- Treatments catalog with category tabs and price ranges
- Team profiles with modal bios, office gallery, technology section
- Insurance & financing page: membership plans with monthly / yearly toggle, financing calculator, benefits-check form
- Reviews carousel (auto-play, swipe, dots), FAQ accordion, marquee, split-text hero animation
- Dark / light theme toggle, fully responsive

**Tech:** HTML5, CSS3 (custom properties, grid), vanilla JavaScript — no frameworks. Photos: Unsplash.

*Concept / demo project — Lumen is a fictional brand. No real bookings, payments or personal data are sent.*
